## 1-Deep copy vs shallow copy 

### deep copy 
```c

char name[5]{"fady"};

char name2[5];


```
انقل بال بfor ده كده deep copy بنقل في memory تانيه معايا الmemory بتاعتي 
المشكلة هنا بتستهلك memory O(n)
في الsize , execution 

### shallow copy 

```c

char name[5]{"fady"};

```
هعمل pointer يشاور على الdata دي بستخدم نفس الmemory مش بعمل memory جديدة 

الميزة انه نفس الذاكرة يعني وفرت في الmemory 
العيب : data access مشترك بين اكتر من pointer  
هنا الmemory O(n) لاني حجزت memory جديدة 

لو فيه اكتر من pointer بيشاور على نفس الmemory هتكون مشكلة افرض حد عمل free هتكون مشكلة بالنسبة ليا كده عندي dangled pointers كتير 


```c

void fun(char x)--> 1Byte  reintrant funtion all var local scope
/*data inside scope deep copy */

void fun(char*x)--> 4byte  non-reintrant funtion 
/*data ouside the scope shallow copy  */
```

## 4-L-Value VS R-Value

### L-value

ممكن نقول عليها located value 

```c

int var = 6;
```

الvar وال 5 ليهم address في الmemory ال 5 مش هعرف اوصل ليها بعدين  

you always can access the value after initialization 

### R-value 

variable exist in one instruction 

### examples

```c
int value=var; --> L & L

int var1 = var2 + var3; --> L & ((L +L )-> R)
```

الR-value مش بتقدر تشيل L-Value
